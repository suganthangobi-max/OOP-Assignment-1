# OOP Assignment 1 – Car Ride Booking System

## Project Description

This is a simple Car Ride Booking System developed using Java for our Object-Oriented Programming (OOP) Assignment 1.

The program uses three main objects: Car, Driver, and Passenger. It demonstrates how these objects work together to simulate a basic ride booking process.

## OOP Concepts Used

The project uses the concepts learned in Chapters 1, 2, and 3:

- Classes and Objects
- Encapsulation (Private Attributes)
- Default and Parameterized Constructors
- Getter and Setter Methods
- Methods and Object Interaction
- Selection Structures (if-else)
- Looping Structures (for loop)

## Project Files

**1. Car.java**

Stores car information such as brand, model, color, year, fuel level, speed, and engine status. It also includes methods to start the engine, drive, and stop the engine.

**2. Driver.java**

Stores driver information such as name, age, licence number, phone number, city, driving experience, and completed trips. It checks whether the driver can drive.

**3. Passenger.java**

Stores passenger information and allows the passenger to book and complete a ride based on their wallet balance.

**4. Main.java**

The main class creates objects and demonstrates how the Car, Driver, and Passenger classes work together.

## How to Run the Program

1. Download the Java files.
2. Open them in a Java IDE such as NetBeans, Eclipse, or VS Code.
3. Make sure all four Java files are in the same project folder.
4. Compile and run `Main.java`.
5. The program will display the ride booking process and final object details.
